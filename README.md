# 夜間毛孩就醫

Vue 3 + Vite 的動物急診查詢作品，Pug template 與縮排式 Sass。查詢頁採 RWD，手機清單在前，桌機左清單右位置區；另有 `/sources/` 資料來源與查核方式頁。

## 資料原則

- 全台 22 縣市都可篩選；目前有 23 間從院所官網人工查閱的樣本，分布於 10 縣市，**不是全台完整名冊**。無樣本的縣市不表示當地沒有動物急診，空白縣市提供農業部開業名冊連結供延伸查詢（名冊不保證夜間急診）。
- `src/data/hospitals.json` 保存院所資料與逐筆查閱日期；`src/data/sources.js` 保存來源與名單整理日期。新增院所時，需逐項核對名稱、電話、地址、24 小時／急診內容與適用動物。
- `allDay` 表示院所公告 24 小時可接急診，不能用 24 小時住院照護代替；「此刻接診」另屬即時資訊。目前沒有即時狀態來源，所有 `openNow` 均為 `null`，相關篩選停用。
- 每張卡片連到自己的官網來源。`src/data/sources.js` 保存政府名冊、整理文章、Google 地圖搜尋與查核說明，集中呈現在 `/sources/`；首頁不顯示來源總表。Google 地圖搜尋只用於發現候選，未直接匯入搜尋結果；空白縣市可外開該縣市的搜尋。
- 右欄逐間使用 Google 地圖「分享 → 嵌入地圖」的 iframe，連結保存在 `src/data/map-embeds.json`，已人工對照院所名稱與地址；不需 API key。新增院所時也要核對嵌入位置，地圖與官網資料可能各自變動。若新院所尚無分享連結，可選擇設定 Maps Embed API key 作為備援；否則顯示地址與外開搜尋／導航連結。
- 卡片顯示官網公告的夜間急診時段；時段是資料查閱時的公告，不代表此刻收治。
- 搜尋條件寫入網址，可分享同一組關鍵字、縣市、行政區、24 小時與急診篩選；不會把使用者位置寫入網址。
- 附近院所與距離排序須先逐筆核對院所座標。現有名單只有地址，未補齊座標前不顯示不可靠的公里數或排序；共用套件已準備距離計算與完整度檢查。

## 物件與元件

- `packages/orange-vue-components` 是獨立 npm 專案，可複製到其他 Vue 3 + Vite 專案，用 `file:` 安裝。含通用欄位、篩選、來源連結、分享網址、距離計算與清單查詢物件。
- `src/domain/HospitalDirectory.js` 繼承通用清單類別，只處理動物醫院的篩選規則。
- `src/components/HospitalCard.vue` 與 `LocationPreview.vue` 是此案專用的展示元件。
- 手機版點選院所會跳到位置資訊，並可返回搜尋結果；桌機維持左清單、右位置區。
- Sass 模組與 Vue SFC 的 Pug／Sass 寫法延續既有切版習慣。新功能先判斷是否跨案共用，再放入元件專案或此案的 `domain/`。

## 後續待辦：附近院所（暫緩）

- 持續擴充並逐筆查核院所資料；現有 23 筆分布於 10 縣市，不足以承諾任一使用者周圍 5 公里內都有收錄院所。
- 資料量足夠後，替每筆地址核對座標與座標來源，再評估各地區「5 公里內有符合條件的院所」的覆蓋率。**5 公里是優先展示範圍的目標，不是固定排除更遠院所的硬門檻。**
- 使用者主動按定位才要求瀏覽器權限；第一層顯示 5 公里內的結果，沒有結果時擴大範圍，並保留更遠院所與手動地區搜尋。拒絕定位仍可使用原本查詢。
- 網站計算的公里數若使用座標，須標示為直線距離；實際路程與時間以外部導航結果為準。不得用行政區中心點或未核對的座標冒充院所位置。
- 上述查核完成前，距離排序維持不上線。`DistanceDirectory` 僅是可重用的計算及資料完整度檢查模組。

## 後續資料接入方向

目前 `hospitals.json` 是手動查核後的靜態樣本，部署時打包進前端；改成 JSON 不會自動同步其他網站。每筆資料以 `id` 辨識院所，保留 `sourceId`、`checkedAt` 與查核備註；`allDay` 僅表示公告 24 小時接急診，`openNow: null` 表示無可信的即時接診資料。

1. 毛孩論壇：發現候選與異動線索，須再查醫院公告，不直接當成可接診名單。
2. 醫院官網／公告：核對名稱、地址、電話、急診時段及收治動物別，記錄查閱日期與來源。
3. Google 搜尋／Google 地圖：協助發現候選與導航；搜尋結果不直接匯入，更不當成即時接診狀態。
4. 第三方資料庫與 API：若日後找到可用且允許使用的資料來源，先將其欄位對應到現有院所格式、去重並核對來源，再由前端讀取自己的 API。是否能自動更新，取決於該 API 的提供方式及資料品質。

切換成後端資料時可保留目前的搜尋、篩選與卡片元件，但要把靜態 JSON 匯入改成非同步取得資料，並處理載入與失敗狀態。

## 執行

```bash
npm install
npm run dev
npm run verify:data
npm run build
```

部署到子目錄（例如 `/night-hospital-map/`）時，把 `dist/` **裡面的內容**放在該目錄下，讓 `index.html`、`assets/`、`favicon.svg` 與 `sources/` 同層；正式網址應以 `/` 結尾。Vite 使用相對資源路徑，首頁及 `/sources/` 都可從站點根目錄或子目錄載入。原始碼 ZIP 需先執行 `npm install`、`npm run build`，不能直接當靜態網站上傳。

目前公開作品直接顯示逐間院所的 Google 地圖分享 iframe，也可外開搜尋與導航，不需 Google API key 或付費；嵌入地圖不會自動同步 `hospitals.json` 的院所資料。若未來新增院所尚無分享連結，可將 `.env.example` 複製為 `.env.local`，填入 `VITE_GOOGLE_MAPS_EMBED_KEY` 作為備援；這項選用功能須先在 Google Cloud 啟用 Maps Embed API 與計費，並將公開於瀏覽器的 key 限制為本站網域及此 API。Google Places API 尚未接入；目前沒有即時接診資料。
